Syntax Highlighting Font Test

This page tests the SyntaxHighlight-Regular.ttf font with JavaScript code:

function calculateArea(radius) { // Calculate the area of a circle const PI = 3.14159; return PI * radius * radius; } // Call the function with radius = 5 let area = calculateArea(5); console.log("The area is: " + area);

The font should highlight JavaScript syntax with different colors:

  • Keywords (function, const, return) in pink (#F92672)
  • Numbers and strings in purple (#AE81FF)
  • Comments in gray (#75715E)
  • Function names in blue (#66D9EF)
  • Regular text in light gray (#F8F8F2)
